# TRCC Linux AUR packaging

`thermalright-trcc` and `thermalright-trcc-git` are unofficial AUR packages.
They are maintained independently of the upstream TRCC Linux project.

Report problems with the Arch package, dependencies, or installation on the
relevant AUR page: [thermalright-trcc](https://aur.archlinux.org/packages/thermalright-trcc)
or [thermalright-trcc-git](https://aur.archlinux.org/packages/thermalright-trcc-git).
For TRCC itself and its official `trcc-linux` package, see the
[upstream project](https://github.com/Lexonight1/thermalright-trcc-linux).
